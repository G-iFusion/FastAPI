# Хенд-офф

Документ для передачи проекта из `README.md`. Адреса серверов, IP, пароли и ключи здесь не приводятся: они только в `.env` на машинах.

## Project Overview

Цель: дать пользователю произведение от 2 до 5 чисел. Числа целые или дроби не длиннее трёх знаков после запятой. Результат не округляется до трёх знаков и считается десятичной арифметикой, без двоичного хвоста.

Пользователь открывает страницу Frontend-сервера, заполняет множители и нажимает «Умножить». Браузер говорит только с Frontend-сервером. Тот вызывает Backend-сервер и подставляет ключ доступа. На Backend-сервере FastAPI передаёт числа агенту LangChain, агент вызывает инструмент `multiply`.

Ключевая ценность: точное произведение и текст агента, при этом ключ OpenAI и ключ доступа к API не попадают в страницу.

Сейчас контейнер Backend-сервера остановлен, чтобы запросы не тратили токены OpenAI. Публичный вызов сервиса отвечает отказом прокси и до модели не доходит.

## Prompt Engineering Guide

Модель берётся из `model_openai`, температура `0`. Отдельного длинного системного промпта нет. Поведение задают два коротких текста.

### Промпт HTTP-запроса

Где: `invoke_agent` в `main.py`. Его вызывает `POST /api/v1/run/{flow_id}`.

Текст:

```text
Перемножь эти числа инструментом multiply. Передай их списком строк без изменений: <числа через запятую>
```

Параметры: в конец подставляется уже проверенный список из 2–5 строк. Пример списка: `1.125, 2, -1`.

Ограничения: сервис принимает ответ только если агент вызвал `multiply` и произведение инструмента совпало с произведением запрошенных чисел. Иначе ответ `502`. Поле `product` в JSON берётся из расчёта сервиса, поле `answer` — из текста агента.

Когда работает плохо:

- агент отвечает текстом и не вызывает инструмент;
- агент передаёт в инструмент другие числа, не тот список;
- запрос не доходит до промпта: нет ключа (`401`), чужой идентификатор сценария (`404`), меньше 2 или больше 5 чисел, либо больше трёх знаков после запятой (`422`).

### Промпт инструмента и терминальный режим

Где: описание инструмента `multiply` в `main.py`. Его видит и HTTP-путь, и команда `.venv/bin/python main.py`.

Текст:

```text
Перемножает от 2 до 5 чисел.
Каждое число передавай строкой: целое или дробь не больше чем с 3 знаками после запятой.
Пример: ["1.5", "2", "-0.25"].
```

В терминале отдельной инструкции нет: в модель уходит произвольная фраза пользователя, например «Умножь 1.125, 2 и -0.5».

Ограничения: инструмент сам проверяет количество чисел и формат. Терминал не сверяет произведение с ответом модели и не требует ключ доступа к API. Ключ OpenAI нужен в обоих режимах.

Когда работает плохо:

- в терминале модель считает сама и не вызывает инструмент, тогда в ответе может появиться неточное произведение;
- пользователь пишет больше трёх знаков после запятой или одно число: инструмент отклоняет вызов;
- формулировка без чисел («умножь эти») не даёт модели, что передать в инструмент.

## Метрики успеха

Технические:

- доля запросов `POST /api/v1/run/{flow_id}` с кодом `200` и полем `product`, совпадающим с произведением переданных чисел;
- доля `502` среди запросов, которые уже прошли проверку ключа и формата чисел: это сбои агента, а не кривой ввод;
- доступность `GET /health`: ожидается `{"status": "ok"}`, пока контейнер запущен.

Бизнес-метрики:

- доля нажатий «Умножить», после которых пользователь видит произведение, а не сообщение об ошибке;
- число вызовов модели на одно успешное произведение: лишние повторы увеличивают расход токенов OpenAI;
- доля запросов, отсечённых до модели (`401`, `404`, `422`): они не должны тратить токены.

## Риски и ограничения

Один общий ключ доступа. Его знает Frontend-сервер и любой другой клиент API, например n8n. Отдельных ключей на интерфейс нет, ограничения частоты запросов нет: при включённом контейнере каждый успешный вызов тратит токены OpenAI.

Агент может не вызвать инструмент. Тогда пользователь не получает произведение, хотя числа уже проверены. Повтор такого запроса снова идёт в модель.

Страница и API принимают не больше пяти чисел и не больше трёх знаков после запятой. Более длинную дробь или свободный текст со страницы отправить нельзя. В терминале свободный текст принимается, но инструмент его не исправляет.
